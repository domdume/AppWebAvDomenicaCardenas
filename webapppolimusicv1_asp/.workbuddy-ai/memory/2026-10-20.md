# 2026-10-20 — PoliMusic (ASP Clásico + SQL Server)

## Trabajo realizado
Desarrollada la pantalla principal de canciones de **PoliMusic** (app de streaming estilo Spotify) en ASP Clásico (VBScript) + ADODB + SQL Server 2025.

### Archivos creados (raíz del proyecto)
- `db_connection.asp` — include ADODB. Prueba providers MSOLEDBSQL → SQLNCLI11 → SQLOLEDB; cadena con `Encrypt=Optional; TrustServerCertificate=Yes;`; login `sa/admin04`; helper `Comando()` para consultas parametrizadas (anti-inyección).
- `login.asp` — autentica contra TBL_USER (consulta parametrizada), crea `Session("username"/"user_type"/"user_photo"/"user_id")`, redirige a songs.asp. Cuentas demo: userNormal/12345678 y userAdmin/12345678.
- `logout.asp` — limpia sesión y `Session.Abandon`, redirige a login.asp.
- `songs.asp` — página principal:
  - Valida sesión (redirect a login si vacío).
  - Bienvenida con foto + nombre + badge ADMIN.
  - RBAC: USER_TYPE=1 ve/usa CRUD; =0 solo lectura+reproduce.
  - CRUD (POST en el mismo archivo) SIEMPRE valida `Session("user_type")=1` en servidor. Delete borra hijos en TBL_PLAYER/TBL_TRACKLIST antes de TBL_SONG (FK).
  - Listado con subconsultas (1 fila/canción) enriquecido con álbum y artista.
  - API AJAX `?accion=play&id=` incrementa PLAYS vía `UPDATE...OUTPUT`.
  - Reproductor `<audio>` en barra inferior controlado por `app.js`.
  - `ResolvePath()`: reemplaza prefijo `~/` por `SongFilesAndImages_resources/`.
- `styles.css` — paleta ORIGINAL negro + salmón (no colores Spotify). Flexbox/Grid, hover en filas, modales CRUD, responsive.
- `app.js` — player (play/pause/seek/volumen/auto-siguiente), contador de plays por AJAX, modales CRUD, validación cliente, fallback SVG para imágenes faltantes (`window.imgError`).

### Notas / decisiones
- Los assets solo traían 1 mp3 (`bensound-adventure.mp3`). Se copió a los 4 nombres faltantes (dreams/energy/sci-fi/tomorrow) en `SongFilesAndImages_resources/SongFiles/` para que las 5 canciones del seed sean reproducibles.
- La BD seed referencia `~/albumImages/...` y `~/ArtistImages/...` que NO existen en los recursos locales → el front muestra placeholders SVG vía `onerror` (datos de álbum/artista sí vienen de BD).
- Requiere IIS con ASP clásico + driver MSOLEDBSQL + BD creada desde `BDD_PoliMusic.sql`, con la raíz del sitio apuntando a esta carpeta.
